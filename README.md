# Morrow downloads

Morrow connects the assistant you already use to your courses. Compare sections, build lessons from your materials, and review course changes before you apply them.

Download Morrow for [Mac with Apple silicon](https://github.com/bradenriggins/morrow-downloads/releases/download/v1.0.0/Morrow-1.0.0-mac-arm64.dmg) or [64-bit Windows](https://github.com/bradenriggins/morrow-downloads/releases/download/v1.0.0/Morrow-1.0.0-win-x64.exe).

[Set up Morrow](https://meetmorrow.app/how-it-works) · [Explore Morrow](https://meetmorrow.app) · [Get help](https://meetmorrow.app/support)

Canvas and Moodle connect through Morrow Bridge in Chrome. Blackboard uses an institution connection set up by your administrator.

This repository provides desktop downloads. Each release includes checksums for its files. Third-party components retain the licenses included with them.
