# Morrow downloads

Morrow connects the assistant you already use to your courses. Compare sections, build lessons from your materials, and review course changes before you apply them.

Download the current Morrow Desktop release for Mac with Apple silicon or 64-bit Windows from [meetmorrow.app/download](https://meetmorrow.app/download).

[Set up Morrow](https://meetmorrow.app/how-it-works) · [Explore Morrow](https://meetmorrow.app) · [Get help](https://meetmorrow.app/support)

Canvas and Moodle connect through Morrow Bridge in Chrome. Blackboard uses an institution connection set up by your administrator.

This repository keeps older Desktop release files and is reserved for a future signed update feed. The current release and its checksums are on [meetmorrow.app/download](https://meetmorrow.app/download). Third-party components retain the licenses included with them.
